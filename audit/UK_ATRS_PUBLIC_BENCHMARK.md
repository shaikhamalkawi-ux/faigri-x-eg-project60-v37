# UK ATRS Public Documentary Benchmark

This audit uses a purposive eight-record education-relevant subset of the official UK Algorithmic Transparency Recording Standard repository. It is a public-document coverage benchmark, not an outcome-validation study.

- Records: 8
- Record-dimension cells: 40
- Direct: 31
- Partial: 9
- None: 0
- All five dimensions direct: 2
- Production records: 4
- Production records with all five direct: 0

## Admission decision

Admitted only for bounded cross-framework documentary-coverage analysis. The dataset is not used to change FAIGRI-X-EG scores, weights, risk anchors, thresholds, veto decisions, or ranks.

## Interpretation boundary

The coding records whether the official ATRS page contains direct, partial, or no public documentary evidence for five broad governance constructs. It does not verify implementation, effectiveness, legality, fairness, or safety in practice. The selected set is purposive and single-analyst coded.
